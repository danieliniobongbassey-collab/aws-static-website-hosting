# AWS Static Website Hosting with Amazon S3 and CloudFront

## 1. Project Overview
This project demonstrates how to design and deploy a secure, scalable, and cost-effective static website hosting solution using Amazon Web Services (AWS).

## 2. Business Scenario
A small business wants to host its corporate website without maintaining physical servers. The business requires secure website delivery, high availability, low latency, and minimal operational overhead.

## 3. Project Objectives
- Host static website content using Amazon S3.
- Distribute website content globally using Amazon CloudFront.
- Secure the S3 origin using Origin Access Control (OAC).
- Enable HTTPS for secure website delivery.
- Test and document the deployed architecture.
- Evaluate the solution's operational costs.

## 4. AWS Services
- Amazon S3
- Amazon CloudFront
- AWS Identity and Access Management (IAM)

## 6. Security Considerations
- Restrict direct public access to the S3 bucket.
- Use CloudFront Origin Access Control.
- Apply least-privilege IAM permissions.
- Deliver website content over HTTPS.
